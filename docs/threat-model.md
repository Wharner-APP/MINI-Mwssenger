# Модель угроз

## Что защищаем

| Актив | Где хранится | Кто может прочитать |
|---|---|---|
| Тело сообщения | устройство (SQLite, AEAD) и конверт (AEAD) | только отправитель и получатель |
| `sign.in` | файл на устройстве пользователя | только пользователь |
| `K_enc`, `K_mac`, приватные ключи | память, `keys.bin` под `KEY_WRAP` | только устройство |
| Пароль | в память клиента, на сервер уходит `PW_KEY` | сервер видит только верификатор |
| Метаданные (логины, время, размер, chat_id) | SQLite сервера | владелец сервера |

## Кому доверяем

- Сервер — доверенный для маршрутизации и аутентификации, но **не** для
  содержимого сообщений.
- TLS-сертификат — самоподписанный; клиент пиннит SHA-256 отпечаток.
  Без совпадения отпечатка HTTPS/WSS не используется (WSS — жёсткий отказ,
  HTTPS — предупреждение только при отсутствии пина, как в §4.2).
- GitHub README — доверенный источник адреса туннеля; при недоступности
  используется последний сохранённый адрес.

## Угрозы и ответы

| Угроза | Ответ в этой сборке | Остаточный риск |
|---|---|---|
| Перехват HTTP | TLS 1.3 + пиннинг | без пина HTTPS полагается на CA |
| Подмена сервера | пиннинг отпечатка | пользователь может подтвердить подмену вручную |
| Чтение БД сервера | тела зашифрованы, сервер не парсит конверт | метаданные видны |
| Подбор пароля | Argon2id, rate limit, блокировки | слабый пароль всё ещё слаб |
| Кража `sign.in` | нужен ещё пароль | оба фактора у одного пользователя |
| Компрометация устройства | `keys.bin` под `KEY_WRAP` | злоумышленник с устройством и `K_enc` читает всё |
| Подмена prekey | подпись Ed25519 проверяется | нет TOFU-баннера при смене ключа |
| Replay/дубли | `client_msg_id` + дедуп на сервере | — |
| Флуд | rate limit на mail send/pull/ack, 100 кадров/с WS | — |
| Утечка секрета капчи | секрет только на сервере, `.env`/`server.toml` в `.gitignore` | — |

## Чего в этой сборке нет

- Forward secrecy (см. `docs/crypto.md`).
- Баннер «Ключ безопасности изменился» и проверка Safety Number в UI.
- Защита метаданных (кто с кем и когда) от владельца сервера.
- Мультиустройство: одно устройство на аккаунт (G02).
- Анонимность: сервер видит IP и логины.

## Секреты

Никогда не коммитятся и не логируются: `server/configs/server.toml`,
`server/configs/captcha.toml`, `master.key`, `.env`, `deepseek.bat`,
`config/captcha.cfg`. Логгер принимает только структурные поля и запрещает
`body`, `text`, `key`, `secret`, `password`, `sign.in`.
